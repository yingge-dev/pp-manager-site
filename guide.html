安装与更新

PP管理器支持 Android 10（API 29）及以上，已在 Android 17 真机上验证。安装包约 5.4 MB，同时包含 arm64-v8a 与 armeabi-v7a。

  1. 从下载页下载 PPManager-v1.2.1.apk。
  2. 在文件管理器里点开 APK；如果系统提示「未知来源」，允许当前应用安装未知应用。
  3. 安装完成后首次启动，按提示授予权限。
升级时直接覆盖安装即可，数据会保留。如果系统提示签名不一致，说明之前装的是别的签名版本，需要先卸载旧版（会清除应用数据）。

权限

所有文件访问权限

Android 11 起，普通存储权限无法访问 Android/data、外置 SD 卡等目录。PP管理器使用系统的「所有文件访问权限」（MANAGE_EXTERNAL_STORAGE）做完整文件管理。

  • 首次启动会引导到系统设置页，找到 PP管理器并打开开关。
  • 如果拒绝，App 仍可使用公共目录，但部分目录需要走 SAF 单独授权。

SAF 文件夹授权

设置 → 权限 → SAF 文件夹授权，可以单独授权 SD 卡、U 盘或某个目录。授权后从 SAF 入口浏览，不需要 ROOT。

ROOT

ROOT 是可选的。授权后可以读写 /system、/data 等系统分区，查看其他应用的数据目录，修改文件权限。没有 ROOT 时，系统分区会显示为只读。

ROOT 下删除系统文件可能导致无法开机。改 /system 之前先备份，确认知道自己在做什么。

文件管理

双窗口与多标签

文件页右上角 ⋮ → 双窗口 可以打开两个并排的窗口。两个窗口各自有标签和历史，点路径栏可以快速切换目录。

  • 长按文件进入多选，再点其他文件追加选择。
  • 底部操作栏支持复制、剪切、删除、更多（批量重命名、对比、压缩、分享、属性）。
  • 复制后在另一个窗口的目录里点「粘贴」，即可跨目录移动。

常用操作

  • 新建：右下角 + 可以新建文件夹或空文件。
  • 重命名 / 属性：点文件 → 更多 → 重命名 / 属性。属性里可以看到路径、大小、时间、权限和 MD5。
  • 删除：默认移入回收站；可在设置里关闭二次确认或回收站。
  • 搜索：文件页右上角搜索，递归扫描当前存储，最多返回 400 条。
  • 排序 / 隐藏文件 / 网格 / 详情：排序面板或设置里切换，立即生效。

压缩包

支持直接打开并浏览：ZIP、TAR、TAR.GZ、TGZ、GZ、7Z、RAR。打开后可以查看条目、单个解压或全部解压到当前目录下的同名文件夹。

  • 压缩：多选文件 → 更多 → 压缩为 ZIP。
  • 解压：打开压缩包 → 右上角「全部解压」。
  • 加密压缩包目前不支持输入密码。

APK 逆向查看

这些工具在「工具」页，全部本地解析，不上传文件。

  • APK 信息：包名、版本、SDK、ABI、DEX 数量、文件数、V1/V2/V3 签名与证书指纹。
  • DEX 查看：从 Download 选择 APK，展开 dex 查看类名、方法数、字段数。
  • 清单查看：把二进制 AndroidManifest.xml 还原成可读 XML。
  • 资源字符串：提取 resources.arsc 全局字符串池，适合快速找文案、URL、资源名。
  • Hex：任意文件按偏移查看字节与 ASCII。
当前版本只做“查看”，不提供反编译为 Java、修改 APK 后重打包或签名替换。需要这些能力请配合 apktool、jadx 等桌面工具。

终端与脚本

工具 → 命令行 / 终端。ROOT 可用时默认以 root 身份启动，提示符是 #；否则是普通用户 $。

  • 支持流式输出、历史命令（上下箭头或历史面板）、停止当前命令、断线重连。
  • 常用命令可以点顶部快捷按钮，避免手机键盘输入符号。
  • 点 .sh 文件 → 执行脚本，会在终端里以脚本模式运行；脚本里的 read 可以从底部输入框拿到输入。
  • 超时会自动熔断，避免卡死。
终端不是完整的交互式 TTY：vi、top 这类全屏交互程序可能显示异常。需要时请用 adb shell 或 Termux。

网络存储

首页「网络与远程」或工具页可以进入 FTP / SMB 与 WebDAV。所有连接配置只保存在本机应用私有目录。

FTP

  • 填写主机、端口（默认 21）、用户名、密码，可选匿名。
  • 使用被动模式（PASV），支持浏览、下载、上传、新建文件夹、删除。
  • FTP 是明文协议，只建议在局域网使用。

SMB

  • 填写主机、共享名（例如 share）、用户名、密码，可选域。
  • 使用 SMB 2/3 协议，支持浏览、下载、上传。
  • Windows 共享需要开启 SMB 2 或更高版本，并确认账号有读写权限。

WebDAV

  • 填写完整地址，例如 http://192.168.1.10:8080/dav/，以及用户名、密码。
  • 支持浏览、进入子目录、返回上级、下载文件。
  • 局域网 HTTP 地址可以直接使用；公网建议用 HTTPS。
  • 当前版本 WebDAV 只支持下载，不支持上传。

设置

  • 外观：跟随系统 / 浅色 / 深色，强调色，AMOLED 纯黑。
  • 文件浏览：显示隐藏文件、文件夹优先、网格视图、显示详情、默认排序。
  • 删除与安全：删除前二次确认、删除时移入回收站。
  • 权限：所有文件访问、SAF 授权、ROOT 状态。
  • 存储：清理缓存，查看各分区占用。

这些开关都会立即生效，不需要重启 App。

赞助与换机

PP管理器不需要注册账号，也不需要登录。所有功能永久免费；¥9.9 永久赞助只是支持开发，并解锁一套金色赞助者界面。

怎么成为赞助者

  1. 在发卡平台购买 ¥9.9 永久赞助卡密（PP1. 开头的一长串）。
  2. 打开 App →「我的」→ 粘贴卡密 → 兑换。
  3. 头像出现金色描边和星标，页面变成金色 SPONSOR 界面，并显示永久赞助者证书。
卡密在本机离线验签，不需要联网、不需要服务器。所有功能仍然免费，不赞助也能使用。

换手机 / 重装怎么办

卡密就是你的会员凭证，不绑定设备。换新手机、恢复出厂或重装 App 后，在新设备打开「我的」→ 输入同一张卡密，永久徽章和金色界面会立即恢复。

  • 在赞助者页面点「复制完整卡密」，保存到密码管理器或发卡平台订单里。
  • 同一张卡密可以在新设备重复输入；它不会被“用掉”。
  • 如果卡密丢失，离线方案没有服务器，无法自动找回；请务必保留购买记录。
  • 因为不绑设备，卡密可能被复制分享；它只会多一个赞助者徽章，不会解锁或影响任何功能。

二期：账号与云同步

如果你以后需要收藏/设置/下载记录跨设备同步，或需要“一张卡密只能绑定一个账号/限制设备”，才需要账号后端。第一期先把赞助和金色界面做好，不引入登录负担。

常见问题

ROOT 显示未授权怎么办？

确认设备已经 root，并且在 KernelSU / Magisk 里给 PP管理器授权。第一次点 ROOT 相关操作时，管理器可能会弹窗询问，选择允许。

为什么 WebDAV 连上却是空的？

先确认地址以 / 结尾，并且服务器允许 PROPFIND。部分网盘的 WebDAV 网关会拒绝第三方客户端，或者需要应用专用密码。错误信息会显示在底部提示条里。

SMB 能连上但很慢 / 上传卡住？

先在系统文件管理器或电脑上确认共享正常。SMB 对网络质量敏感，大文件请保持屏幕常亮并留在前台。部分老式 SMB1 设备需要开启 SMB2 兼容模式。

删除的文件去哪了？

默认在回收站：首页 → 回收站。如果关闭了「删除时移入回收站」，删除就是直接删除，无法在 App 内恢复。

为什么安装包只有 5.4 MB？

没有广告 SDK、没有统计 SDK、没有云端服务。压缩包和逆向解析使用轻量库，界面用 Compose 编写。

源码可以公开吗？

项目使用 Apache-2.0 许可，源码目前是私有仓库。可以通过 GitHub 主页联系作者。
